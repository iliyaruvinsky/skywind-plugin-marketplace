## [1.0.0] - 2025-10-14

### Added
- Initial release of Testing Agent plugin
- Comprehensive testing rules for 6 technology stacks:
  - SAPUI5 (QUnit, OPA5, UIVeri5)
  - ABAP (ABAP Unit, ATC, eCATT)
  - OData (Gateway Client, Postman)
  - Java (JUnit 5, Mockito, AssertJ)
  - JavaScript (Jest, Vitest, Mocha+Chai)
  - React (React Testing Library, Jest, Cypress/Playwright)

### Features
- Testing pyramid enforcement (70% unit, 20% integration, 10% E2E)
- Technology-specific best practices
- Test execution workflow (Analysis → Creation → Execution → Reporting)
- Quality gates and coverage requirements
- Anti-patterns to avoid
- CI/CD integration guidelines
- Honest reporting enforcement
